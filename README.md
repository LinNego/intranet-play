# intranet-play

内网联机的终端小游戏合集。Go 编写，TCP + 一行一条 JSON，Host 权威、无中心服务器，同一网段开箱即玩。

| 游戏 | 人数 | 入口 |
|---|---|---|
| 五子棋 | 2 人 | `intranet-play host` / `intranet-play join` |
| 斗地主 | 3 人 | `intranet-play ddz host` / `intranet-play ddz join` |
| 21 点 | 2~6 人 | `intranet-play bj host` / `intranet-play bj join` |
| 炸金花 | 2~6 人 | `intranet-play zjh host` / `intranet-play zjh join` |

UI 刻意做成"数据面板"的样子（`nx-sync`），在工位上不显眼。

---

## 快速开始

### 五子棋（2 人）

```powershell
# 房主
.\intranet-play.exe host -port 9988 -name Alice

# 对手
.\intranet-play.exe join -addr 192.168.1.23:9988 -name Bob
```

房主先按提示设定棋盘大小（10-20）与先手方，然后输入坐标落子。

命令：`x,y`（如 `7,7` 或 `a,2`）| `chat TEXT` | `resign` | `restart` | `leave`

### 斗地主（3 人）

**房主也占一个座位**，所以三个人各开一个终端：

```powershell
# 房主（座位 0）
.\intranet-play.exe ddz host -port 9988 -name Alice

# 玩家 2（座位 1）
.\intranet-play.exe ddz join -addr 192.168.1.23:9988 -name Bob

# 玩家 3（座位 2）
.\intranet-play.exe ddz join -addr 192.168.1.23:9988 -name Cara
```

三人到齐后，房主输入 `start` 开始。房间是严格的 3 人局，第 4 个连接会收到 `room full` 并被断开。

| 命令 | 作用 |
|---|---|
| `play 55` | **按牌面出牌**：对 5 |
| `play 34567` | 顺子 3-7；`5556` 三带一、`334455` 连对、`5555` 炸弹、`wW` 王炸 |
| `play #3 #7` | **按手牌编号出牌**：编号就是界面上手牌前的 `#n`，`#3-#7` 表示区间 |
| `hint` | 列出所有能压过上家的出法，写法可直接复制成下一条命令 |
| `bid 0` / `bid 1..3` | 叫分，`0` 表示不叫；叫 3 分立刻定地主 |
| `pass` | 不要（拥有自由出牌权时必须出牌，不能 pass） |
| `next` | 本局结束后开下一局（房主或任一玩家都可发起） |
| `start` | 房主开局 / 打完一场后重开 |
| `chat TEXT` | 聊天 |
| `help` | 命令帮助 |
| `leave` | 退出房间 |

出牌写法：每个字符就是一张牌的点数，**同点数重复几次就是几张**——
`5` 单张、`55` 对、`555` 三张、`5556` 三带一、`34567` 顺子、`33344456` 飞机带单。
10 写作 `T`（也接受 `0` 或单独写 `10`），大小王是 `w`（小王）和 `W`（大王）。
记不住就敲 `hint`，它会给出当前所有能压过上家的出法，例如：

```text
log: 可以压过顺子(7): 单张(T) play T | 对子(5) play 55 | 炸弹(2) play 2222 | 王炸 play wW
```

不想数牌面也行：界面上手牌带 `#n` 编号，用 `play #3 #7` 按编号出牌。

规则要点：

- 一副 54 张，每人 17 张 + 3 张底牌；叫分 1/2/3 定地主，底牌归地主且三家可见
- 牌型：单张、对子、三张、三带一、三带二、顺子(≥5)、连对(≥3 对)、飞机、飞机带单、飞机带对、四带两单、四带两对、炸弹、王炸；顺子/连对/飞机不含 2 和王
- 炸弹与王炸每出现一次倍数 ×2；春天 / 反春天再 ×2
- 单局分 = 底分 × 叫分 × 倍数；地主赢则地主 +2 倍、每个农民 −1 倍，反之亦然
- 默认打 10 局（`-rounds` 可改，`-rounds 0` 不限局数），`-base` 调底分
- 3 人局无法托管：有人掉线本局立即作废回大厅，房主重新 `start`

牌面里 `w` / `W` 是大小王，`♠♥♣♦` 是花色；手牌按牌力降序编号（界面上的 `#n`），出牌后重新编号。

### 21 点（2~6 人）

```powershell
# 房主（也是玩家）
.\intranet-play.exe bj host -port 9988 -name Alice -chips 100 -seats 4

# 其他人
.\intranet-play.exe bj join -addr 192.168.1.23:9988 -name Bob
.\intranet-play.exe bj join -addr 192.168.1.23:9988 -name Cara
```

人齐后房主输入 `start`。下注阶段每个闲家 `bet 10`，**全员下注完自动发牌**。

**谁坐庄**由 `-dealer` 决定：

| 取值 | 含义 |
|---|---|
| `auto`（默认） | **3 人以上轮流坐庄**；2 人用虚拟庄家（否则每局都有一半人没牌可打） |
| `rotate` | 强制轮流坐庄：每轮换一个人坐庄，他不下注、也没决策（按规则自动补牌） |
| `virtual` | 强制虚拟庄家：程序坐庄，所有人都是闲家、都下注 |

| 命令 | 作用 |
|---|---|
| `bet 10` | 下注（也可写 `押 10` / `下注 10`）；坐庄那局不用下注 |
| `hit` / `要` | 要一张牌 |
| `stand` / `停` | 停牌 |
| `double` / `双倍` | 双倍下注：加注一份、只补一张、自动停牌（仅限起手两张时） |
| `next` | 结算后开下一轮 |
| `start` / `restart` | 房主开局 / 重开一桌（把中途加入的人也带进来） |
| `chat TEXT` / `help` / `leave` | 聊天 / 帮助 / 退出 |

规则要点：

- 52 张（不含大小王），每局重新洗牌；点数 2-10 按面值、J/Q/K 记 10、A 先按 11 算（爆牌时降为 1，界面会显示"软 x 点"）
- **庄家暗牌在结算前只显示 `?`**，公共报文里没有它的牌面（玩家坐庄也一样，自己也不知道暗牌）
- 庄家点数 <17 必须要牌、≥17 停（软 17 也停）；**闲家全部爆牌时庄家不补牌**
- 黑杰克（起手两张 21 点）赔 3:2；平局退还注额；庄家爆牌时未爆的闲家通吃
- **筹码是"真"的**：初始 100（`-chips` 可改），下注时即扣、结算按净输赢退还；**输光就出局**（座位标 `[出局]`），不再下注也不再坐庄，等房主 `restart` 重开一桌
- **下注上限**：闲家的注额不能超过"庄家赔得起"的额度（按黑杰克 1.5 倍预留），界面会告诉你本局最多押多少——这样不会出现庄家欠账
- **坐庄资格**：轮到你坐庄但筹码不足 `1.5 × 闲家数`（连每人押 1 注都赔不起）→ 直接判出局
- **整桌结束**：只剩一个人没出局，他就赢到最后，房主可 `restart` 重开
- 轮庄模式下筹码只在玩家之间流动（不凭空产生）；对局中有人掉线，本局作废回大厅

界面里座位行会标 `[庄]`（本局坐庄）和 `[出局]`；坐庄那局不会给你出牌命令，看别人打就行。

### 炸金花（2~6 人）

```powershell
# 房主（也是玩家）
.\intranet-play.exe zjh host -port 9988 -name Alice -chips 100 -ante 1 -maxstake 20

# 其他人
.\intranet-play.exe zjh join -addr 192.168.1.23:9988 -name Bob
.\intranet-play.exe zjh join -addr 192.168.1.23:9988 -name Cara
```

人齐后房主输入 `start`。每人 3 张牌，**开局你看不到自己的牌**，要看就得 `look`。

| 命令 | 作用 |
|---|---|
| `look` / `看牌` | 看自己的牌（免费，随时可用；看完变"明牌"） |
| `call` / `跟` | 跟注：明牌付 `注额`，闷牌付一半（最低 1） |
| `raise 6` / `加 6` | 加注到 6（要高于当前注额、不超过上限），按新注额付钱 |
| `fold` / `弃` | 弃牌（本局已投入的不退） |
| `compare 1` / `比 1` | 花一份跟注跟座位 1 比牌，输的人出局 |
| `next` | 结算后开下一局 |
| `start` / `restart` | 房主开局 / 重开一桌 |

规则要点：

- 牌型从大到小：**豹子 > 同花顺 > 金花 > 顺子 > 对子 > 散牌**；**花色不参与比较**
- `A23` 是最小的顺子（按"3 最大"算），`QKA` 最大，`AK2` 不算顺子
- **闷牌半价**：没看牌时跟注/比牌只付一半，所以"闷着打"更省筹码
- **闷牌平局占优**：比牌时两张牌完全一样大 → 恰好一方闷牌则闷牌方赢；都明或都闷则**主动比牌的一方输**
- **比牌的牌面只有你们俩看到**，其他人只看到谁出局
- 一圈 = 所有在局玩家各行动一次；到 `-maxrounds`（默认 6）之后**只能比牌或弃牌**，防止全闷无限跟
- 注额到 `-maxstake`（默认 20）之后不能再加注；筹码不够付跟注只能弃牌
- 筹码输光即出局；只剩一人有筹码时整桌结束，房主 `restart` 重开
- 对局中有人掉线，本局作废回大厅（他的牌是暗的，别人没法替他决策）

## 连不上怎么办

1. **确认地址**：`join` 要填房主机器的**局域网 IP**（`ipconfig` / `ip addr` 查看），不是 `127.0.0.1`（除非同一台机器开多个终端）
2. **放行端口**：Windows 防火墙首次运行会弹窗，要允许"专用网络"；或手动放行 TCP 9988
3. **同一网段**：确认两台机器在同一 Wi-Fi / 交换机下，`ping` 得通
4. **中文与颜色**：建议用 Windows Terminal；老 conhost 下如需手动切码页，执行 `chcp 65001`

目录结构：

```text
cmd/intranet-play/      命令行入口（host / join / ddz / bj / zjh）
internal/protocol/      一行一条 JSON 的消息定义（五子棋 + DDZ_* + BJ_* + ZJH_*）
internal/netx/          TCP 连接封装（inbox channel + 写锁）
internal/game/          五子棋棋盘引擎
internal/ddz/           斗地主规则引擎（牌型判定、比较、对局状态机）
internal/bj/            21 点规则引擎（点数、要牌/停牌/双倍、庄家、筹码结算）
internal/zjh/           炸金花规则引擎（三张牌牌型、底注/跟注/加注/看牌/比牌、奖池）
internal/room/          房间编排：五子棋 2 人；ddz_* 3 人；bj_* / zjh_* 2~6 人
internal/ui/            终端界面（bubbletea）：tui.go / ddz.go / bj.go / zjh.go
docs/开发计划.md          五子棋开发计划
docs/斗地主开发计划.md     斗地主开发计划与实施进度
docs/21点开发计划.md       21 点开发计划与实施进度
docs/炸金花开发计划.md     炸金花开发计划
```

设计约定：

- **权威只在房主**：客户端只发命令、只渲染收到的视图，绝不本地推演
- **手牌按需单播**：斗地主发牌即单播手牌；炸金花**看牌之后才下发**，没看牌时连自己的牌都不在报文里
- **出牌用 cardID**：客户端上报的是牌 ID，房主校验归属，无法伪造
- **隐藏信息要有测试兜着**：斗地主的公共视图、21 点的公共报文、炸金花的公共报文与手牌时机都各有一条断言
- **协议向后兼容**：未知 `type` 一律忽略，方便以后加字段
